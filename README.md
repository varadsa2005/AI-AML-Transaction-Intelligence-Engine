AI AML & Transaction Intelligence Engine
Overview

AI AML & Transaction Intelligence Engine is a full-stack fintech analytics and anti-money laundering (AML) monitoring system built using Python, Streamlit, MySQL, scikit-learn, and NetworkX.

The system simulates realistic banking transactions, detects suspicious activity using machine learning and AML rules, generates alerts, performs risk scoring, and visualizes suspicious money flow networks.
